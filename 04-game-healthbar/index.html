A small game HUD study: the fill, number and status all tell the same story. Low health adds a warning shape. These are original SVG assets, not screenshots from a game engine.

Design boundary: static artwork only. The labels belong in the game's text and accessibility layers when used in an engine. SVG's image metadata does not create an in-game screen-reader interface.

Source dimensions: 420 × 104 with a viewBox. No scripts, external artwork, fonts, tracking or network resources are embedded in the SVGs.
